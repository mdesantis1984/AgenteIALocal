## 📋 Descripción General

El sistema de internacionalización (i18n) de **Agente IA Local** permite cambiar el idioma de la interfaz de usuario en tiempo real sin reiniciar Visual Studio. Soporta múltiples idiomas de forma dinámica mediante archivos JSON externos que la comunidad puede contribuir.

### ✨ Características Clave

- 🌍 **Multi-idioma dinámico**: Español, inglés, francés + ∞ extensible
- 🔄 **Hot reload**: Cambios en archivos JSON se reflejan inmediatamente
- 📦 **Fallback embebido**: Español (Argentina) embebido como respaldo
- 🎨 **UI reactiva**: Cambio de idioma actualiza TODA la interfaz automáticamente
- 🗂️ **Persistencia separada**: `language.json` independiente de `settings.json`
- 🌐 **Contribuciones community**: Sistema extensible para agregar idiomas

### 📊 Idiomas Soportados

| Código | Idioma | Estado | Ubicación |
|--------|--------|--------|-----------|
| `es-AR` | Español (Argentina) | ✅ Activo | Embebido (fallback) |
| `en-US` | English (United States) | ✅ Activo | Externo (JSON) |
| `fr-FR` | Français (France) | ✅ Activo | Externo (JSON) |
| `*-**` | Cualquier idioma | ⏳ Extensible | Contribución community |

### Flujo de Cambio de Idioma

```
1. Usuario click RadioButton (ej: English)
   ↓
2. Event handler: Radio_enUS_Checked()
   ↓
3. LocalizationService.SetLanguage("en-US")
   ↓
4. _current = _external["en-US"]  (cambio diccionario activo)
   ↓
5. LanguageSettingsStore.Save(new LanguageSettings { current = "en-US" })
   ↓
6. LanguageChanged.Invoke(this, EventArgs.Empty)
   ↓
7. LocalizationProvider.OnLanguageChanged()
   ↓
8. PropertyChanged("Item[]")  (notifica TODOS los bindings)
   ↓
9. WPF re-evalúa {loc:Translate ui.config.sidebar.idioma}
   ↓
10. UI actualizada ✅
```

### 2. LocalizationService

**Ubicación:** `src/AgenteIALocal.Localization/LocalizationService.cs`

**Características:**

```csharp
public class LocalizationService : ILocalizationService
{
    // Diccionarios de idiomas
    private Dictionary<string, JObject> _external = new Dictionary<string, JObject>();
    private JObject _current;
    private string _currentLanguageCode;

    // FileSystemWatcher para hot reload
    private FileSystemWatcher _watcher;
    private Timer _debounceTimer;  // 500ms debounce

    // Constructor
    public LocalizationService(string languagesRoot)
    {
        // 1. Copiar archivos desde VSIX a %LOCALAPPDATA%
        CopyDefaultLanguageFilesFromVsixInstallation();

        // 2. Cargar idioma embebido (es-AR)
        LoadEmbeddedFallback();

        // 3. Cargar idiomas externos (en-US, fr-FR, etc.)
        LoadExternalLanguages();

        // 4. Detectar idioma automático (VS → OS → default)
        string detectedCode = DetectLanguage();

        // 5. Activar idioma detectado
        ActivateLanguage(detectedCode);

        // 6. Iniciar FileSystemWatcher
        WatchFiles();
    }

    // Lookup nested key
    public string GetString(string key)
    {
        // Split "ui.config.sidebar.idioma" → ["ui", "config", "sidebar", "idioma"]
        string[] parts = key.Split('.');
        JToken token = _current;

        foreach (string part in parts)
        {
            token = token?[part];
            if (token == null) return key;  // Fallback: retorna key raw
        }

        return token.ToString();
    }

    // Cambio inmediato de idioma
    public void SetLanguage(string code)
    {
        if (!IsLanguageAvailable(code)) return;

        ActivateLanguage(code);
        
        // Persistir
        var settings = new LanguageSettings { current = code, autoDetect = false };
        new LanguageSettingsStore(_languagesRoot).Save(settings);

        // Notificar cambio
        LanguageChanged?.Invoke(this, EventArgs.Empty);
    }

    // Hot reload con debounce
    private void OnFileChanged(object sender, FileSystemEventArgs e)
    {
        _debounceTimer?.Stop();
        _debounceTimer = new Timer(500);  // 500ms
        _debounceTimer.Elapsed += (s, args) =>
        {
            ReloadLanguage(GetLanguageCodeFromPath(e.FullPath));
            LanguageChanged?.Invoke(this, EventArgs.Empty);
        };
        _debounceTimer.Start();
    }
}
```

**Métodos clave:**
- `LoadEmbeddedFallback()`: Carga es-AR embebido (readonly)
- `LoadExternalLanguages()`: Escanea `Languages/*/strings.json`
- `DetectLanguage()`: VS → OS → fallback
- `ActivateLanguage(code)`: Cambia diccionario activo
- `WatchFiles()`: FileSystemWatcher con debounce 500ms

### 3. TranslateExtension

**Ubicación:** `src/AgenteIALocalVSIX/Localization/TranslateExtension.cs`

**MarkupExtension para XAML:**

```csharp
public class TranslateExtension : MarkupExtension
{
    public string Key { get; set; }
    public string FallbackValue { get; set; }

    public override object ProvideValue(IServiceProvider serviceProvider)
    {
        // Retorna Binding (NO string estático)
        var binding = new Binding
        {
            Source = LocalizationProvider.Instance,
            Path = new PropertyPath($"[{Key}]"),  // Indexer
            Mode = BindingMode.OneWay,
            FallbackValue = FallbackValue ?? Key
        };

        return binding.ProvideValue(serviceProvider);
    }
}
```

**Uso en XAML:**

```xaml
<!-- Sintaxis -->

<!-- Uso básico -->
```

### 4. LocalizationProvider

**Ubicación:** `src/AgenteIALocal.Localization/LocalizationProvider.cs`

**Wrapper con INotifyPropertyChanged:**

```csharp
public class LocalizationProvider : INotifyPropertyChanged
{
    private ILocalizationService _service;
    public static LocalizationProvider Instance { get; } = new LocalizationProvider();

    // Indexer para Binding
    public string this[string key]
    {
        get => _service?.GetString(key) ?? key;
    }

    // Inicializar con servicio
    public void Initialize(ILocalizationService service)
    {
        _service = service;
        _service.LanguageChanged += OnLanguageChanged;
    }

    // PropertyChanged para reactividad
    private void OnLanguageChanged(object sender, EventArgs e)
    {
        // Notifica TODOS los bindings (Item[] es el indexer)
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs("Item[]"));
    }

    public event PropertyChangedEventHandler PropertyChanged;
}
```

**Flujo reactivo:**
```
SetLanguage("en-US")
  → LanguageChanged event
  → OnLanguageChanged()
  → PropertyChanged("Item[]")
  → WPF re-evalúa TODOS los {loc:Translate}
  → UI actualizada ✅
```

### 5. LanguageSettingsStore

**Ubicación:** `src/AgenteIALocal.Localization/LanguageSettingsStore.cs`

**Persistencia separada:**

```csharp
public class LanguageSettingsStore
{
    private readonly string _filePath;

    public LanguageSettingsStore(string languagesRoot)
    {
        // %LOCALAPPDATA%/AgenteIALocal/language.json
        _filePath = Path.Combine(
            Path.GetDirectoryName(languagesRoot),
            "language.json"
        );
    }

    public LanguageSettings Load()
    {
        if (!File.Exists(_filePath))
        {
            // Defaults
            return new LanguageSettings
            {
                current = "",  // Fuerza detección automática
                autoDetect = true
            };
        }

        string json = File.ReadAllText(_filePath);
        return JsonConvert.DeserializeObject<LanguageSettings>(json);
    }

    public void Save(LanguageSettings settings)
    {
        // Atomic write con temp file
        string tempPath = _filePath + ".tmp";
        string json = JsonConvert.SerializeObject(settings, Formatting.Indented);
        
        File.WriteAllText(tempPath, json);
        File.Move(tempPath, _filePath, overwrite: true);
    }
}
```

**Ventaja:** Archivo separado evita conflictos con `settings.json` (round-trip preservation independiente).

## 🔄 FileSystemWatcher (Hot Reload)

### Configuración

```csharp
_watcher = new FileSystemWatcher(_languagesRoot)
{
    Filter = "*.json",
    NotifyFilter = NotifyFilters.LastWrite | NotifyFilters.FileName,
    IncludeSubdirectories = true,
    EnableRaisingEvents = true
};

_watcher.Changed += OnFileChanged;
_watcher.Created += OnFileChanged;
_watcher.Deleted += OnFileChanged;
```

### Debounce Timer

```csharp
// Evita recargas múltiples en ediciones rápidas
private void OnFileChanged(object sender, FileSystemEventArgs e)
{
    _debounceTimer?.Stop();
    _debounceTimer = new Timer(500);  // 500ms
    _debounceTimer.Elapsed += (s, args) =>
    {
        // Recargar idioma modificado
        string code = GetLanguageCodeFromPath(e.FullPath);
        ReloadLanguage(code);
        
        // Notificar cambio (UI se actualiza automáticamente)
        LanguageChanged?.Invoke(this, EventArgs.Empty);
    };
    _debounceTimer.Start();
}
```

## ⚙️ Detección Automática de Idioma

### Prioridad

```csharp
private string DetectLanguage()
{
    // 1. Visual Studio locale (DTE.LocaleID)
    // NOTA: Deshabilitado por problemas de referencia EnvDTE
    // string vsLocale = GetVsLocale();
    // if (!string.IsNullOrEmpty(vsLocale)) return vsLocale;

    // 2. Sistema Operativo
    string osLocale = CultureInfo.CurrentUICulture.Name;  // ej: "es-ES"
    
    // 3. Fallback idioma base
    if (osLocale.StartsWith("es-"))
    {
        // Español de España → Español de Argentina
        return "es-AR";
    }
    
    // 4. Default
    return "en-US";
}
```

### Fallback Idioma Base

```
es-ES (España) → es-AR (Argentina)
es-MX (México) → es-AR
en-GB (UK) → en-US (USA)
fr-CA (Canadá) → fr-FR (Francia)
```

```csharp
private void LoadIdiomaControls()
{
    var service = AgenteIALocalVSIXPackage.LocalizationService;

            Source = new BitmapImage(new Uri($"pack://application:,,,/AgenteIALocalVSIX;component/Languages/flags/img/{lang.Code}.png")),

            Height = 40,
            HorizontalAlignment = HorizontalAlignment.Center
```

## 🏷️ Pattern: Tag Invariante

### Problema

```xaml
<!-- ❌ PROBLEMA: Comparación de texto traducido -->
<ComboBoxItem>
    <TextBlock Text="{loc:Translate ui.config.llm.runmode.agente}" />
</ComboBoxItem>
```

```csharp
// Code-behind
string selected = (cbi.Content as TextBlock).Text;  // "Agente" (español) o "Agent" (inglés)
if (selected == "Agente")  // ❌ FALLA en inglés/francés
```

### Solución

```xaml
<!-- ✅ SOLUCIÓN: Tag invariante -->
<ComboBoxItem Content="{loc:Translate ui.config.llm.runmode.agente}" Tag="agente" />
<ComboBoxItem Content="{loc:Translate ui.config.llm.runmode.preguntar}" Tag="preguntar" />
```

```csharp
// Code-behind
string selected = (cbi.Tag as string);  // "agente" (invariante)
if (selected == "agente")  // ✅ FUNCIONA en TODOS los idiomas
```

**Aplicado en:**
- ComboBox RunMode (Chat + Config)
- ComboBox Provider (Config)
- DataTriggers (ícono Flash verde)
