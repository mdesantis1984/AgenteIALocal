# Support — Agente IA Local VSIX

## Report an issue
Please report issues at the project repository's GitHub Issues page: https://github.com/mdesantis1984/AgenteIALocal/issues

When creating an issue, include:
- Visual Studio version (e.g., Visual Studio 2022/2026 + edition).
- Extension version (e.g., v1.0.46).
- Steps to reproduce the problem.
- Relevant logs: `%LOCALAPPDATA%\AgenteIALocal\logs\AgenteIALocal.log`.
- Any configuration `settings.json` (redact API keys).

## What to attach
- Screenshots of the ToolWindow or error dialogs.
- A trimmed copy of the `AgenteIALocal.log` file showing the time range of the incident.
- The `settings.json` (with sensitive fields removed).

## Security note
Do not include API keys or other secrets in public issue reports. If you must share secrets with maintainers, use a secure channel.

## Support scope
This support guide covers installation, basic troubleshooting, and reporting bugs. For feature requests, please open an issue labeled "enhancement".
